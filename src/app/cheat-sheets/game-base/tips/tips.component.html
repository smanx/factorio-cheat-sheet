常用快捷键

Factorio 常用快捷键。表格仅列出 macOS 不同的快捷键。
Windows/Linux macOS 说明和技巧
Alt 显示实体的详细信息。或点击快捷栏中的 ALT 按钮。
M 打开或关闭地图视图。
O 打开或关闭火车视图。
P 打开或关闭生产视图。
MMB CMD + RMB 清除快捷栏中的物品。或在货运车厢和库存中设置过滤器。
R 顺时针旋转蓝图（或已建造的实体）。
Shift + R 逆时针旋转蓝图（或已建造的实体）。
CTRL + LMB 放入或取出全部物品。
CTRL + RMB 放入或取出半堆物品。
Z 在光标处丢下 1 个物品。可以用来向组装机或箱子中放入单个物品。
F 从地面或传送带上拾取物品。
Shift + LMB 建造蓝图。
Shift + RMB 复制实体配置。
Shift + LMB 粘贴实体配置。
Q 从库存中选择光标悬停的物品。如果悬停在矿物上：选择库存中最好的采矿机。
CTRL + X CMD + X 剪切。
CTRL + C CMD + C 复制。
CTRL + V CMD + V 粘贴。
CTRL + Z CMD + Z 撤销。
CTRL + Y CMD + Y 重做。
Numpad + 增大可建造图块（如填海料、混凝土等）的尺寸。
Numpad - 减小可建造图块（如填海料、混凝土等）的尺寸。
Shift + RMB 清除蓝图或解构规划器的过滤器。
Shift + LMB 在地面和地图上标记。
~ 打开聊天/命令行。
关于复制/粘贴
  • 复制/粘贴配置适用于机械臂、组装机、请求箱、运算器等。
  • 通过将组装机的配置复制/粘贴到请求箱来设置请求箱。这会请求足够 30 秒生产的物品。
  • 通过拖动鼠标将配置复制/粘贴到多个实体。
  • 复制单个格子（库存、货运车厢）。

命令 （这些命令不会禁用成就）

  • /permissions，禁用制作 - 对获取懒惰混蛋成就很有用。
  • /screenshot [x分辨率] [y分辨率] [缩放] - 用于制作大型/高清截图。
    （分辨率可选，默认为当前窗口大小；缩放可选，默认为 1）。
  • [item=iron-plate] / [fluid=crude-oil] - 富文本的一部分，会显示为图标！对蓝图/火车站名称很有用。
    快速获取物品的富文本标签：打开控制台，然后对物品（例如在库存、箱子中）Shift+LMB。
    该物品的富文本标签会出现在控制台中，可以复制。

调试菜单 （F4 或 F5）

一些有用的选项：

  • show-fps - FPS/UPS
  • show-multiplayer-statistics - 延迟
  • show-tile-grid、show-raw-tile-transitions - 精确建造
  • show-rail-paths - 减少被火车撞的可能性
  • show-transport-line-gaps - 识别未饱和的传送带
  • show-player-robots - 清楚显示是否有掉队的机器人
  • allow-increased-zoom - 允许增大缩放

其他

  • 战斗：武器射程对比图。
  • 机械臂总是将物品放在传送带的最远侧，并优先从最近侧取物品。
  • 在蓝图上建造会保留配方。
  • 流体可以通过锅炉、储液罐和电力采矿机（仅采铀矿时）流动。
  • 可以从地图视图使用蓝图。
