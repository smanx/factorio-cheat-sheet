常用机器比例列表，用于最优生产物品而不停滞。
例如：制作"铁轨"时，正确的比例是 1 个"铁棒"组装机供应 2 个"铁轨"组装机。
如果没有机器混合（组装机/化工厂/熔炉），则不同组装机等级之间的比例保持不变。

前往本页的链接部分，查找蓝图和计算器。

如何手动计算？

  • Recipe Item Rate(items/second) = [Recipe Item Count(items) / Recipe Craft Time(seconds)] * (Machine)Craft Speed Multiplier
  • 然后增加机器数量以匹配输入/输出速率，从而得到机器比例。
  • 使用 异星工厂百科 通过在游戏中对任何物品按 Alt + 鼠标左键 来获取配方详情
  • 这个 通用生产比例工具 可以帮助你跟踪这些计算。

火箭组件

{{ item.name }}

  • 一枚火箭需要 100 个 火箭组件。
  • 要获得 太空科技包 （发射井中无产能插件）；
    你需要每种火箭组件各 1000 个（100*10），加上制作 卫星所需的物品。
    • 这是一个比例为 (1100i * 10s) : (1050i * 15s) : (1100i * 15s) = 11000 : 15750 : 11000。
    • 简化后的比例为：44 : 63 : 44（将上述比例除以 250）。
    • 其中 20 秒和 30 秒分别是配方的制作速度。
  • 上述比例产生 2.5 科技包/分钟，但发射井可以产生 2.9 科技包/分钟。
  • 上述比例是近似值：在发射井中使用 3 级产能插件加 1 个插件效果分享塔中的 1 级速度插件，发射井能够产生 3.9 科技包/分钟。
